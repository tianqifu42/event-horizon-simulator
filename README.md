physics.js: Core physics engine calculating geodesic light tracing via a 4th-order Runge-Kutta (RK4) integrator, gravitational time dilation τ=t1−Rs/r\tau = t\sqrt{1 - R_s/r}τ=t1−Rs​/r​, gravitational lensing deflection angles, Novikov-Thorne thermal accretion disk spectra T(r)T(r)T(r), and Schwarzschild post-Newtonian gravity corrections near the event horizon. engine.js: Orchestrates interactive particle systems (stellar dust, orbiting stars), dynamic gravitational wave ripples (GW quadrupole emissions), relativistic bipolar jets, and keyboard/mouse mechanics for pilotable spaceship physics.

index.html: A polished, sci-fi glassmorphism HUD featuring real-time telemetry, sandbox controls (Supernova waves, Black Hole mergers, and particle spawner actions), and toggles for optics overlays (Einstein Ring lensing grid, Photon Sphere at 1.5Rs1.5R_s1.5Rs​, and ISCO boundary at 3Rs3R_s3Rs​).
